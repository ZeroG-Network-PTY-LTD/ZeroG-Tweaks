# ZeroG Bees - Complete Blockbench asset stack (Minecraft Java 1.21.1)

This package consolidates every named non-bee asset from the supplied classic and modern design sheets.

- 19 modeled frames: seven space frames plus all twelve standard alveary frames
- all eight standard apiary tools, Magnetic Bee Scoop and animated Habitat Locator
- Portable Beealyzer, serum items, Honey Drop and animated Genetic Splicer
- Standard Apiarist armour and Cosmic Apiarist armour as wearable player rigs
- all machines, controllers, materials, block faces and named registry variants
- seven exact tier assemblies plus the Cosmic Alveary catalog presentation model

Bee entity projects remain deliberately excluded. Runtime registration, custom item predicates, GUIs and full-bright renderer bindings still belong in the NeoForge 1.21.1 mod code.


## Complete item coverage

Every registered item now has a matching Blockbench source: 65 standalone item projects and 85 block inventory projects. The block inventory projects preserve the matching block geometry, embedded textures and UVs while adding GUI, first-person, third-person and ground display transforms.
