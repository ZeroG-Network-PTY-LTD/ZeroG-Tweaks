# Concord Vault

The Prism Sentinel arena, v4: an underground complex of mine corridors and rooms around the Sentinel chamber, which is
built from 4 keys. The full explanation and the rules for designing rooms are in
`docs/zero-g-tweaks-bundle/briefs/concord_vault.md`.

- `build_concord_vault.py` writes every template in `templates/`. The chamber reuses `build_prism_arena_v3.py`.
- `templates/` is a copy of `1.21.x` `data/zerog_tweaks/structure/concord_vault/` (bd4ab216).
