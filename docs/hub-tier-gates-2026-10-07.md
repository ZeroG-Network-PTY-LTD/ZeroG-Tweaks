Face north from the central spawn. Stand on a gate's central pad, empty-hand right-click its controller, choose a destination with the page arrows, click **Engage**, then **Ready** before the countdown finishes. Return controllers use the same ready flow and bring you back to their original hub pad. Other destinations prepare their return platform on first travel.

Only the northern exhibit/return-platform region files and gate ledger are installed from a tested copy of the same world. The Overworld hub's other sectors, level/player data and inventories are not replaced. Previously existing north-region edits are retained in that copy except matching old gate parts; the one-time migration does not run again after you start editing the new gates. Existing planetary landing gates remain usable.

Server checks cover all six formed tiers, free admin routing, six representative destination/return platforms, persistence and repeat-migration preservation. Client appearance, clicks and actual travel in your installed modpack remain for your inspection. The [delivery receipt](hub-tier-gates-and-card-icons-delivery-2026-10-07.json) records exact installed bytes, scoped save changes and test evidence. No world seed or terrain-wide regeneration is introduced.

Return preparation now loads an existing gate's complete footprint before checking it. Visual launch payloads are sent only to connections that negotiated those payloads, avoiding the mock-player regression without removing supported clients' animations. The older whole-planet audit/export still assumes34 fixed outbound exhibits; adapting that separate fixture is explicitly retained on the TODO ledger rather than counted as passed.
