# Mining ladder tags (v1.3)

The block tags for the ZeroG mining ladder. Design doc: **Gear > Mining ladder**. Sheet: `../../sheets/gear/mining_ladder.png`.
Generated by `../../generators/mining_ladder.py`. Edit the ladder there and re-run; don't hand-edit these files.

## Install (goes on `1.21.x`)
Copy `data/` onto `src/main/resources/data/`, **replacing** files with the same name. Three files on `1.21.x` change meaning:
- `minecraft:needs_diamond_tool` no longer lists Nullifite. It moved to `zerog_tweaks:needs_netherite_tool`.
- `zerog_tweaks:needs_nullifite_tool` now holds Ferrox, not Aresite.
- `zerog_tweaks:needs_olympium_tool` now holds Aresite and Cobaltium, not Cerulite.

The vanilla `incorrect_for_{wooden,stone,iron,gold,diamond,netherite}_tool` tags gain the ZeroG levels above them, so vanilla tools can't mine past the ladder.
This works with vanilla tools **before** any Java exists: netherite mines Nullifite, and diamond doesn't.

## Java (M1)
Each set's `SimpleTier` uses `zerog_tweaks:incorrect_for_<set>_tool` as its incorrect-blocks tag and the mining speed from
`data-manifest.json > mining_ladder.mining_speed`. Precious sets keep enchantability 25.
Run `./gradlew build` and `runClient`, then check that a diamond pick can't drop Nullifite and a netherite pick can.
