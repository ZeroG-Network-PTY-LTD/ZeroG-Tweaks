# Native runtime admission — 1.0.8 candidate

The existing six authored species remain the visual authority. `admit_runtime.py`
copies their geometry and animations byte-for-byte to GeckoLib **4** paths in
the Java 1.21.1 code branch, not the GeckoLib 5 paths mentioned in older source
notes. Source art is preserved.

For each species, three authored colour styles are composited with the thirteen
original profession overlays plus an unassigned appearance. Corresponding
transparent glow masks are retained: 504 runtime PNGs altogether. Six inventory
eggs use Minecraft's native spawn-egg model and species-coordinated colours.

Runtime admission does not create new concept art or claim a client/GPU visual
review. Native villager AI, ordinary jobs/trading and offspring are used first.
The six signature jobs, custom trades, lore abilities, custom zombie variants
and profession-specific held props remain future gameplay work.
