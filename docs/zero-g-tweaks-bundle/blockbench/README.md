# ZeroG Minecraft 1.21.1 Blockbench assets

Open `index.html` for the searchable current gallery: 69 creature looks, 38 eggs, 65 drops and 52 optional aura previews (224 editable projects). Open individual `.bbmodel` files in Blockbench; creature projects use the GeckoLib format and require its Blockbench plugin. The HTML uses only refreshed current generated designs.

- `mobs/`: 28 ZeroG creatures with anatomy refinements, joint hierarchies and animation drafts.
- `../../shattered-skies/blockbench/`: 41 Shattered Skies looks across 10 base creatures. In the ZIP these are under `shattered-skies/blockbench/`.
- `mob_drops/`: 65 transparent item projects, with front and back faces, using the original item shape definitions.
- `auras/`: combined creature-and-aura preview projects, with a second embedded texture and a pulse animation. Runtime exports keep the aura geometry and texture separate.
- `previews/`: software-rendered geometry previews and contact sheets.
- `spawn_eggs/`: 38 vanilla-shape coloured previews and editable two-face item projects. Runtime eggs use the original vanilla layers plus an original untinted accent, not the baked preview PNG.
- `references/`: the 82-mob Minecraft 1.21.1 animation inventory, a current asset index and a recoverable retirement record for 56 obsolete exports.
- `validation.json`: dimensions, UV coverage, hierarchy membership, animation references and file hashes.

Entity texture atlases are painted at eight pixels per source model unit; the four guardian models are then enlarged without stretching anatomy or enlarging atlases. Their final texel density is recorded in `mobs/manifest.json`. This is a custom HD choice, not strict vanilla texel density. Item textures are 64×64. PNG textures are embedded in every project. Entity exports, animations and glow masks are included under `assets/`. Glow masks need an emissive render layer in the eventual Java renderer.

The remastered pass uses discrete five-tone color ramps, clustered fur/wool, scale seams, horn rings, crystal facets and painted edge accents. Membranes, fins and cloaks use two-sided planes. Eye positions follow `sheets/mobs/data/mob_eye_styles.csv` at repository commit `57b173b`, including its explicitly marked proposed entries. The user's later six-panel single-eye image supplies texture direction, not gameplay overrides. Single-eye mobs retain their existing bodies with one centred pointed eye: multicoloured crystal Prismling, fiery Flare Sprite, violet vortex Dying Star, teal fractured Splinter adds, cratered Crater Drifter, and ember-cracked Ash Strider. Prism Sentinel uses the repository's proposed single-eye placement. Transparent corners, dark pupils and bright iris masks replace the former rectangular pairs on these mobs. Front/side review links are included on every creature gallery card; `face_audit.json` checks visibility, not artistic correctness.

Bog Lurker, Gildcrab and all Shardmother looks now have two articulated eye stalks above the head. The stalks swivel in idle and the eye bones blink. Gaze clips rotate real heads rather than sliding whole eyes through cheeks; torso-mounted eyes have intentionally empty gaze clips until pupil-only UV controls are wired. All eye/controller clips are editable drafts: they require independent runtime control and do not play automatically. Suggested randomized blink timing is 3–7 seconds alongside locomotion.

Tidewraith and all four looks now use the eight vanilla Minecraft 1.21.1 Phantom cuboids, body/head rest pitch, wing-base-to-tip and tail-base-to-tip hierarchy. Java Y-down coordinates are converted to Y-up and the vanilla half-pixel X bias is recentered for symmetry. The original fantasy manta/dragon geometry and tendrils are replaced in generated output; authored historical JSON stays intact as provenance. Original HD pixel scales, the inherited look's skin/belly palette, paired manta gill decals and side eyes provide the requested redesign. The flight clip samples the actual 16-degree cosine wing motion and double-frequency tail flex from the installed mapped source. Software previews honor rest rotations; native interpolation/controller behavior is unverified.

Only Prism Sentinel, Rift Tyrant, Eidolon Captain and The Dying Star have the repository's six-times-player rule: 10.8-block model height and specified 3.6 × 10.8-block gameplay hitbox. Proportional geometry, joint pivots and position keyframes are scaled once; runtime renderers must not apply another 6× scale. Hitbox registration remains pending. Frost Warden/Sun Colossus mini-bosses and Shattered Skies bosses retain their authored scales.

Aura overlays are an optional artistic addition, with low-opacity colored rings and a 3-second pulse. Use a translucent emissive render layer with the mob transform and normal depth testing. They do not add Minecraft block light. Vanilla Phantom inspiration concerns its luminous eyes and wing/tail hierarchy; a green aura is not a default vanilla feature. Glow squid likewise appear luminous without producing light.

Shattered Skies geometry and inherited palettes come from `docs/shattered-skies/models/`, except the explicitly requested Phantom-derived Tidewraith. ZeroG source definitions are in `generators/mobs_data.py` and `mobs_food.py`; anatomy/eye overrides are in `mob_anatomy.py` and `mob_faces.py`. Drop silhouettes/palettes come from `food_data.py`. Original texture art is generated locally. Minecraft model structure was used as requested, but no vanilla textures, source jars or client jars are redistributed.

## Local CLI

From the repository root, use `python3 docs/zero-g-tweaks-bundle/generators/zero_g_assets.py doctor` to check capabilities, `list` to list creature ids, or `validate` for read-only static checks. `build --overwrite --zip` rebuilds the stack and replacement ZIP. `review --overwrite --zip` refreshes audits, animation previews, HTML and ZIP without repainting models. `open tidewraith` requests opening that existing project in the installed Windows Blockbench. Launching is not proof of successful native import. This CLI wraps local generators; it is not Blockbench's native command API or the separate `game-dev` package tool. No paid provider is invoked.

The 38 spawn eggs now reference the original vanilla Minecraft egg shell and spot textures, retaining their registered mob-specific tint colours. Original small star accents, or violet splinters for Shattered Skies, use an untinted third texture layer. See `spawn_eggs/spawn_eggs_preview.png` and `spawn_eggs/manifest.json`; the original vanilla textures are referenced at runtime, not copied into this package. Regenerate with `generators/build_spawn_egg_accents.py`. These egg asset changes have not been tested in the Minecraft client or incorporated into a newly built JAR. Eggs remain placeholders until entity implementations and renderers are registered. This package does not implement AI, spawning, combat abilities, particle effects or drop behavior. Animation clips are editable drafts; their runtime transitions still need wiring and testing. `crystal_shard` is a design-only item asset because this branch has no corresponding registered item model.

Static UV, hierarchy and rig validation has passed. Native Blockbench inspection and Minecraft client testing have not been completed. The 56 obsolete ZeroG creature exports in `geckolib/models/entity` and `geckolib/animations/entity` have been retired with verified recoverable backups outside the active repository; armour assets are untouched. Current creature exports are in `geo/` and `animations/`. The pending renderer example now uses explicit resource paths and matching clip names; it remains unwired example code, not a tested live renderer. Historical authored concept specifications are retained as source provenance, but are not shown as current gallery designs.

Dune Burrower follows the user's Silverfish direction: low sand/chitin segments, six small legs, antennae, narrow tail and a compact face. Segment-specific phases provide a lateral wriggle. Moon Hopper's hop moves paired limbs; Shattered Skies shins/feet follow upper-leg phases. GIFs evaluate generated keyframes in software and do not prove native import or runtime controller behaviour. The custom preview renderer uses per-pixel depth testing; translucent gel/aura sorting is still approximate.
