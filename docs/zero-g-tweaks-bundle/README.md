# ZeroG Tweaks: full package

Everything made so far for the ZeroG Tweaks mod (NeoForge 1.21.1). All art is placeholder-quality pixel art, and nothing has been loaded in game yet.

| Folder | What's inside |
| --- | --- |
| `ZeroG_Tweaks_Design_Doc.md` | The full design doc (export of the live doc) |
| `resources/` | Drop into `src/main/resources`: `assets/zerog_tweaks` (textures, blockstates, models, lang) and `data/` (recipes, loot tables, tags) |
| `java/` | Food values, food item classes, bottle and shearing interactions, plus a README with registration notes |
| `sheets/materials_and_blocks/` | Ore sets, teleporter and machine blocks, terrain and building blocks, stone families |
| `sheets/gear/` | Tools and armor icons per world |
| `sheets/armor/` | Worn armor reference sheets (front and back), one per set |
| `sheets/mobs/` | 28 mob and boss reference sheets |
| `sheets/food_and_items/` | Meats, crops and dishes, mob materials, rewards and boss drops, wood sets, crops and glow layers |
| `generators/` | The Python scripts that generated the art and JSON, so everything can be regenerated or tweaked |

Known gaps: custom effects (Freeze Ward, slowness immunity), the Acid fluid's Java, tinted models for wasteland blocks, GeckoLib armor extras and Blockbench mob models.
