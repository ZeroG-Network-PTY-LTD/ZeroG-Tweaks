# ZeroG Tweaks v1.2: full package (design locked)

Everything made so far for the ZeroG Tweaks mod (NeoForge 1.21.1 + GeckoLib 4.x). All art is placeholder-quality pixel art, and nothing has been loaded in game or compiled yet.

| Folder | What's inside |
| --- | --- |
| `ZeroG_Tweaks_Design_Doc.md` | The full design doc (export of the live doc) |
| `resources/` | Drop into `src/main/resources`: textures, blockstates, models, lang, GeckoLib models and animations (`assets/`), plus recipes, loot tables and tags (`data/`) |
| `java/` | Foods, effects, Acid fluid, wasteland colour handler, GeckoLib entity and armor renderers, interactions; see java/README.md |
| `sheets/materials_and_blocks/` | Ore sets, teleporter and machine blocks, terrain and building blocks, stone families |
| `sheets/gear/` | Tools and armor icons per world |
| `sheets/armor/` | Worn armor reference sheets (front and back), one per set |
| `sheets/mobs/` | 28 mob and boss reference sheets |
| `sheets/food_and_items/` | Meats, crops and dishes, mob materials, rewards, wood sets, crops and glow layers |
| `sheets/liquids/` | The six liquids: animation frames, buckets, fog colours, mixing |
| `sheets/models_and_tinting/` | Wasteland tinting by galaxy, mob models and armor models rendered from the exported files |
| `generators/` | The Python scripts that generated the art and files |

Locked on 2026-09-29 as v1.2 (v1.0 plus gear stats and abilities, and the six liquids).
