# Art-direction concept references

Generated using the built-in image-generation tool on 2026-10-05 (user timezone Asia/Bangkok). These original concept sheets are previews, not runtime texture atlases, GPU renders or validated 32×32 sprites. No third-party resource-pack art is included.

## Items and vegetation

`items-and-vegetation-concept.png`: compare Enhanced Vanilla, Soft Shading and Magitech Accents on matching ingot, sword, jelly, grass, crop stages, melon and climbing-vine subjects. User approved C for weapons/armor/ingots/dusts and a blend of A/C for vegetation. Prompt constraints: crisp nearest-neighbor-like pixel clusters, hue-shifted shadows, restrained accent glow, readable silhouettes, visible produce stages; avoid smooth painterly gradients, mixed pixel sizes and excessive halos.

## Planetary terrain

`planetary-terrain-concept.png`: six rows (Moon, Mars, Cerulon, Skarn, Eidolon, Solvane), four columns (ore, dirt, dry farmland, wet farmland). The approved comparison sheet was used as a style reference only. Prompt constraints: isometric Minecraft-like blocks, approximately 32×32 face detail, shorter farmland with parallel furrows, matching soil sides, wet soil darker than dry; distinct lunar-gray, rusty ochre, teal, charcoal/ember, frosty violet and sandy gold planetary palettes; uneven mineral deposits instead of circuit boards; preserve natural soil. Pending user approval of this new terrain sheet.

## Delivery status

The image files are preserved in the Design checkout. They have not been copied into runtime textures or installed in the CurseForge client. Native game texture creation, model bindings, animation metadata and visual verification remain separate implementation steps. The Moonsteel hand-display rotation fix builds successfully but does not implement this art refresh. Neither sheet demonstrates working emissivity, emitted world light, seamless tiling or actual crop growth.
