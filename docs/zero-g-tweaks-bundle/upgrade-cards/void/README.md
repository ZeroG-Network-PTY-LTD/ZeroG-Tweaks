# Void card source binding

This matches the native 1.21.x model and reuses the approved filter-card icon.
Dedicated artwork remains pending a supplied/approved reference; this is not a
newly authored texture. Do not introduce flat placeholder sprites.

The fourth native processor card socket accepts one Void Card. Its Upgrades
panel edits36 saved item-type ghost entries across four scrollable pages.
Selection copies the cursor item's type without consuming it; right-click clears.
With the card installed, only newly produced matching outputs are suppressed.
Existing stored outputs and all inputs/catalysts/player items remain untouched.
Other machines and new crafting costs are outside this implementation.

Follow docs/art-direction-lock.md and docs/zero-g-upgrade-concepts.md for future
original ZeroG artwork and mechanics. The latter is a roadmap, not implemented
sound dampening, gas recovery, factory conversion or chunk loading.
