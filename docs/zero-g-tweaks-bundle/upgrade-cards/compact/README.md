# Compact card bindings — 7 October 2026

These six source bindings match the native 1.21.x item models. They reuse the
existing approved filter-card icon; they are not newly authored Compact artwork.
Dedicated Compact/Void examples have been requested and remain pending.

Cards have reagent capacities 212, 360, 508, 656, 804 and 952. Runtime uses
normal-sized visible stacks plus separate component-aware reserves. Catalysts,
outputs and player inventories are not enlarged. The middle processor socket
accepts one Compact card; legacy cooling items remain take-out only.

Do not generate bland replacement icons or imply oversized ItemStacks are safe.
Use the approved C equipment/material palette, clean silhouette, consistent
pixel scale, hue-shifted highlights/shadows and selective bright accents after
the owner supplies/approves the dedicated reference. No new art is approved here.

Void filtering, its UI and exact survival crafting costs remain outstanding.
See Docs/docs/compact-storage-2026-10-07.md for delivery and testing scope.
