# Small Hollow Fleet wreck — first implementation

Source requirement: Galaxy 4 tracker, Derelict Wrecks on Eidolon. Original19x9x27 damaged ship, two rib-damage variants, local Frozen Regolith foundation, Hull Plating/Corroded Hull shell, open central corridor and side breaches. Existing Cryo Pods, Broken Consoles and Spectral Lanterns are used without new textures or story logs. One accessible chest uses unchanged `chests/derelict_wreck` loot.

Run `generate_derelict_wreck.py --resources <code resources>` for matching runtime/Design resources. Frozen Graveyard only, dry-land jigsaw, six-block maximum surface-height difference,32-block search radius,40-chunk spacing/20 separation. These are conservative initial placement settings, not final rarity balance. No artificial boss spawns or large-wreck encounter; those remain separate tasks.

Template placement and loot tests are separate from ordinary natural-world evidence and client visual approval. This is an original small layout implementing the tracker, not a recreation of an unavailable concept image.
