# ZeroG Tweaks help — Minecraft 1.21.1

Use the [1.21.x code branch](https://github.com/ZeroG-Network-PTY-LTD/ZeroG-Tweaks/tree/1.21.x)
with Java 21, NeoForge 21.1.252 and GeckoLib 4.9.3 for NeoForge 1.21.1.
The current jar is a development candidate; it has not been tested inside the
ZeroG CurseForge modpack. Back up saves before testing, and do not keep duplicate
versions of this mod in mods/. No automatic installation occurred.

Press G in-world for the multiblock reference guide. Rotate/tilt by dragging,
zoom with the wheel, select layers from Y=0 and click cells for part coordinates.
Genetics and cryo are separate external modules. This is a schematic only, not
automatic construction, world ghost blocks, machine processing or validation.

Open original .bbmodel projects from the
[Design collection](https://github.com/ZeroG-Network-PTY-LTD/ZeroG-Tweaks/tree/Design/docs/asset-collection-1.21.1)
in Blockbench. Category showcases are lighter than the full scene; combined
showcases are static, whereas individual projects retain their animation clips.
GitHub shows HTML source; download the collection to view review.html locally.

See [the illustrated guide](https://github.com/ZeroG-Network-PTY-LTD/ZeroG-Tweaks/blob/Docs/docs/current-collection-guide-1.21.1.md)
for armour, items, Bees, mobs, eggs/drops and unfinished gameplay. Report bugs
with the exact mod versions, reproduction steps and latest.log, omitting tokens
or personal/private information.
