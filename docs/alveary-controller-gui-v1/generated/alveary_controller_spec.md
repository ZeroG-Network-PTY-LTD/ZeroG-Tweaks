# Alveary Controller: screen layout and textures

One controller screen serves all seven alveary tiers (Rustic to Quantum Queen Chamber). The screen is the same size at every tier; parts the structure does not have yet are shown sealed, so players can see what the next tier adds. Classic 1.12 bee-mod look: vanilla grey window and slots, recessed panels with a honey strip, Forestry-style ledger tabs on the right.

Generated by `controller_gui.py`: every number below comes from the same data that drew the textures.

## Screen

- Size 256 x 250 GUI px; `imageWidth = 256`, `imageHeight = 250`. Centre it like any container screen.
- Title at (8, 5), colour `0x404040`, no shadow. Inventory label at (47, 158).
- Fits the default GUI scale on 1080p; at GUI scale 4 on 1080p it is too tall, as with other large mod screens.

## Gauges

- Each gauge well is 10 x 50; the fill is drawn from `fill_*` sprites at (+1, +1), bottom-up, height = synced value (0-48).
- The tolerance band is drawn 4 px left of the well with `tol_band` (repeat per px) and `tol_tick` at both ends. Green band = the queen can work.
- `needle` (10 x 2) is drawn across the well at the current value so the value reads even when it is inside the band.
- Temperature steps (bottom to top): Icy, Cold, Cool, Normal, Warm, Hot, Hellish (7 px each). Humidity: Arid, Normal, Damp. Gravity: 0.5 g at the bottom, 1.3 g at the top, Overworld 1.0 g at 30 px.
- Tooltips: "Temperature: Warm (queen tolerates Normal-Hot)", same pattern for the others.

## Texture style rules

- Window: vanilla container bevel (1 px black outline, 2 px white top-left, 2 px #555555 bottom-right, fill #C6C6C6).
- Slots: vanilla 18 x 18 (#373737 top-left, white bottom-right, #8B8B8B inside). The queen slot is 26 x 26 with an amber inner ring.
- Panels: recessed #B6B4AC with a 2 px honey strip (#B07016 over #E8A82C) along the top, so each section reads as one unit.
- Wells (gauges, bars, tanks): near-black #24221F with the slot bevel, so fills pop.
- No baked text in any texture; all words come from lang keys, so the screen translates.
- Palette: honey #E8A82C / #B07016 / #FFD678, wax #F0D696, grey ramp #FFFFFF #C6C6C6 #8B8B8B #555555 #373737.
