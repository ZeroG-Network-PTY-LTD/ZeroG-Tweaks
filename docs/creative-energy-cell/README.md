# Creative GFE cell — original source artwork

Run `python3 generate.py CODE/src/main/resources/assets/zerog_tweaks`.
Native32×32, eight frames, three ticks/frame with interpolation. Gold uses the
locked Solvanite six-tone ramp; the core has restrained violet/white C accents.
Beveled chassis, fasteners and sequential indicators retain coherent pixel density.
The inventory and placed cube share one animation atlas. No borrowed mod artwork.

`texture-preview.png` and `pulse-preview.gif` are enlarged source previews,
not proof of in-game appearance. Runtime block light15; shader appearance pending.
