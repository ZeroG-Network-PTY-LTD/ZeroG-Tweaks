# Original upgrade-card source art

Run `generate.py --code <1.21.x checkout> --gallery <Docs gallery PNG>` after previous art generators. Source PNGs, manifest and preview stay on Design; runtime PNG/model bindings belong to 1.21.x; documentation gallery belongs to Docs.

Original transparent 32x32 magitech sprites with hue-shifted highlights, no source-image crops or borrowed artwork. Tier palette: copper, verdant, cyan, azure, violet, gold. Six bottom rank positions redundantly encode tier. Centre symbols distinguish speed arrows, energy coil, compact stacks and an untiered Void vortex. Void is not given invented tiers. No item IDs, effects, recipes or display positioning change.

Pixel glow is an artwork highlight, not a claim of dynamic emitted light. Generate after the older placeholder-card generators so they cannot restore shared icons. Client approval of actual inventory rendering remains separate.
