# Charge-driven energy cells — 7 October 2026

Original native 32×32 pixel casings, six tier accents and nine charge states.
Animated gauges use eight frames, three ticks per frame, with no interpolation.
Amber marks low charge, cyan marks intermediate charge and green marks high charge.
Filled segments are controlled by the existing actual charge state, not random colours.

Run `generate.py CODE_CHECKOUT` **after** the older transport generator to retain this
artwork in both runtime resource layers. Geometry, normalized UVs, capacity and port
contracts are unchanged. `manifest.json` records every PNG/metadata hash.

`preview.png` and `preview.gif` are enlarged nearest-neighbour source previews,
not screenshots of a Minecraft render. Client/shader approval remains outstanding.
