## Before pressing Start

1. Open **Items / Recipes**. Read every input quantity, alternative and catalyst rule.
2. Set item/fluid/power faces to supported input or output roles. A visible connector alone is not proof of transfer.
3. Check FE and output space. Recipe browsing never processes or moves items.
4. Consult **Upgrades**: compatibility is machine-specific; generator Flux Modules are not Acceleration cards.
